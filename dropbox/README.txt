THƯ MỤC THẢ DỮ LIỆU

Mỗi bộ dữ liệu = một thư mục con, ví dụ:
  dropbox/churn-2026/train.csv
  dropbox/churn-2026/test.csv
  dropbox/churn-2026/task.md      <- mô tả: mục tiêu, cột nhãn, metric, ngân sách GPU

- Tên thư mục trùng tên dự án đã có -> dữ liệu bổ sung cho dự án đó.
- File PDF đặt thẳng ở đây -> agent nghiên cứu paper.
- Chép xong, đợi tối đa ~30 phút (cron) hoặc nhắn /scan trên Telegram.
- Dữ liệu gốc không bị di chuyển hay xoá.
