- Mục tiêu: dự đoán khách hàng rời bỏ trong 30 ngày tới
- File huấn luyện: train.csv — cột nhãn: churn (0/1) — cột id: customer_id
- File cần dự đoán (nếu có): test.csv
- Metric: AUC (cao hơn tốt hơn)
- Ngân sách GPU: 10 giờ
- Ràng buộc / ghi chú: không dùng cột signup_date (rò rỉ thông tin)
